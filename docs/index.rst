Finding your way around
=======================

These docs are split by what you need right now:

- **Tutorials** are lessons to work through when you're new. Start here.
- **How-to guides** answer "how do I ...?" when you have a job to do.
- **Reference** is the dry description of every knob iommi has.
- **Explanation** covers the thinking behind iommi, so your code comes out idiomatic.
